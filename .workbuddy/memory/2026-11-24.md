# 2026-11-24

## 菜单图标支持自定义 SVG

- 在 `src/App.tsx` 新增图标工具：`CUSTOM_ICON_VALUE`（下拉框哨兵值）、`INVALID_ICON_SVG`（红色叉号错误图标）、`parseSvgIcon`（DOMParser 校验 + 补 `xmlns` + 序列化，带 200 条上限缓存）、`iconSignature`/`matchIconChoice`（按路径 `d` 比对预设图标）。
- 新增 `MenuIconPicker` 组件，“修改菜单图标”和“添加菜单”两个对话框共用：下拉框末尾追加“自定义 SVG”，选中后展开代码输入框、实时预览，解析失败时预览转错误样式并禁用保存。
- `SvgIcon` 现在对无法解析的图标回退为错误图标（`.svg-icon.is-invalid`），历史脏数据不会再显示成空白。
- 数据层未改动：图标仍写入 `navigation_menus.icon_svg`，通过 `save_app_preferences` / `create_navigation_menu` 保存，不需要新增 migration。
- 图标渲染始终走 CSS mask（`background-color: currentColor`），因此 SVG 内的 `fill` 不生效；需要特定颜色时用类覆盖背景色。
- `src/App.css` 追加 `.icon-picker`、`.icon-preview`、`.svg-icon.is-invalid`、`.svg-icon-input`、`.dialog-hint`、`.svg-validation` 样式。
- 验证方式：`pnpm build` 通过；用临时 vite 别名 + Playwright 把 Tauri `invoke` 换成内存桩，跑通“错误回退 → 自定义输入 → 保存 → 侧边栏同步”全流程（临时 harness 已删除）。
