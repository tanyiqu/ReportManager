## 便携式运行与数据目录

应用图标由项目根目录的 `logo.png` 生成，主窗口、Windows 任务栏和系统托盘均使用该图标。点击窗口关闭按钮会隐藏到系统托盘，进程和本地数据保持可用；单击或双击托盘图标、选择“显示主窗口”，以及再次启动可执行程序，都会恢复现有主窗口。托盘菜单还提供“退出程序”，用于完全结束应用。

发布版本会在可执行文件同级创建 `data` 目录，并将 SQLite 数据库及后续配置文件保存在其中；复制整个程序目录即可一并迁移数据。请将程序放在当前用户有写入权限的目录中运行（例如自定义安装目录或便携目录）。开发模式的数据保存在 `src-tauri/data`，以免被构建清理脚本删除。

主窗口会在前端首帧渲染完成后显示，避免启动时出现短暂的空白页面。

## 清理构建产物

在项目根目录双击或在命令行执行 `clean.bat`，可删除可重新生成的前端构建目录、Tauri/Rust 编译产物、Tauri 能力定义缓存、Vite 缓存、覆盖率目录和项目日志。

该脚本不会删除 `node_modules`、源代码、配置文件或应用本地数据；需要重新安装依赖时请自行执行 `pnpm install`。
